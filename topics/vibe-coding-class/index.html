HOW AGENTS WORK
에이전트는 이렇게 일해요
01 · UNDERSTAND

이해

사용자의 요청을 분석해서 진짜로 원하는 게 뭔지 파악해요.

02 · PLAN

계획

큰 문제를 작은 단계로 나누고, 어떤 도구가 필요할지 결정해요.

03 · ACT

실행

도구를 직접 사용해서 단계를 하나씩 실행해요.

04 · CHECK

확인

결과가 진짜 맞는지 스스로 검증해요. 이상하면 다시 시도해요.

05 · REPORT

보고

다 끝나면 "이렇게 했어요" 라고 사람에게 정리해서 알려줘요.
